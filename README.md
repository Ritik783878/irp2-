## How to Run

Make sure Python 3 is installed. Open a terminal in the project directory and run:

```bash
python problems/p1_reverse_words.py
python problems/p2_binary_search.py
python problems/p3_digit_sum.py
python problems/p4_pair_count.py
```

Enter each program's input through standard input.

## Testing

Use the matching `tests/pN_input.txt` as input and compare the program output with `tests/pN_expected.txt`.
